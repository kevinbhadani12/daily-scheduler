Connect to your GitHub repo

The dashboard saves your settings into the repo, so it needs a GitHub access token. The token is kept only in this browser.

  1. Open GitHub → New fine-grained token.
  2. Repository access: Only select repositories → your daily-scheduler repo.
  3. Permissions: Contents: Read and write and Actions: Read and write.
  4. Generate, copy and paste it below.
